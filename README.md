# Elsewhere — Travel Journal

## English

Elsewhere is a responsive five-page travel journal for curious people and thoughtful journeys. The site focuses on slow travel, memorable places, and the freedom to find your own way.

### Pages

- **Home** — a visual introduction to the Elsewhere point of view
- **Destinations** — curated places to begin a journey
- **Experiences** — different ways to travel, from slow mornings to open landscapes
- **Journal** — short stories and field notes from the road
- **About** — the idea behind Elsewhere

### Built with

- Semantic HTML5
- CSS3 with responsive breakpoints
- Google Fonts: Playfair Display and DM Sans
- Unsplash photography

### Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Português

Elsewhere é um diário de viagens responsivo com cinco páginas, criado para pessoas curiosas e jornadas mais conscientes. O site valoriza o turismo sem pressa, lugares marcantes e a liberdade de encontrar o próprio caminho.

### Páginas

- **Home** — uma introdução visual à proposta do Elsewhere
- **Destinations** — uma seleção de lugares para começar uma viagem
- **Experiences** — diferentes formas de viajar, de manhãs tranquilas a paisagens abertas
- **Journal** — histórias curtas e anotações de viagem
- **About** — a ideia por trás do Elsewhere

### Tecnologias

- HTML5 semântico
- CSS3 com layout responsivo
- Google Fonts: Playfair Display e DM Sans
- Fotografias do Unsplash

### Executar localmente

Abra o arquivo `index.html` no navegador ou sirva a pasta usando qualquer servidor de arquivos estáticos.
